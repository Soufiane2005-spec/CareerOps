# CareerOps — Target Users

## Primary Users

CareerOps is designed primarily for students, recent graduates,
and junior technology professionals searching for internships
and entry-level opportunities.

The first version focuses on candidates interested in:

- DevOps
- Cloud Engineering
- Cybersecurity
- DevSecOps
- Backend Engineering
- Infrastructure roles

## User Problems

Target users commonly face the following problems:

- job opportunities are spread across many platforms
- it is difficult to identify which opportunities match their skills
- candidates do not always know which skills they are missing
- application tracking is often manual
- follow-up dates can easily be forgotten
- different CV versions may be used for different applications

## CareerOps Value

CareerOps aims to provide one place where users can:

- discover opportunities from authorized sources
- compare opportunities against their skill profile
- identify missing skills
- track applications
- manage CV versions
- receive reminders for follow-ups and interviews

## Initial Scope

The MVP focuses on internships and junior technology positions.

CareerOps will not initially target senior or executive roles.
